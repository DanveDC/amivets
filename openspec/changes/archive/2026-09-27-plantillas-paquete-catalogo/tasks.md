Wrapped that `db.commit()` in `try/except IntegrityError` → `db.rollback()` + the same 409 "Ese servicio ya es un componente de este paquete" (same pattern as `backend/app/routers/areas.py`). No reliable e2e test for the race itself (needs two truly concurrent requests); verified by reading the diff and the existing sequential-duplicate test (`componente repetido da 409`) still passing unchanged.
